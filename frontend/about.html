Training recipe

Exact configuration used in backend/train.py.

Architecture

MobileNetV2 pretrained on ImageNet → average-pool → Dropout → Dense-256 (ReLU) → Dropout → softmax over 38 classes. Backbone frozen except the last blocks, fine-tuned on GPU.

input 224×224 · Adam · PyTorch

Data & augmentation

PlantVillage-38: 70,295 train / 17,572 validation images. One-time decode cache; flip, rotate ±15°, zoom, shift and brightness all computed on the GPU.

gpu-aug · memmap cache

Schedule

Up to 25 epochs, EarlyStopping (patience 4, keeps best), ReduceLROnPlateau (×0.3), mixed precision. Best result: 88.7% validation accuracy at epoch 14.

python -m backend.train --data ./data_raw --epochs 25
